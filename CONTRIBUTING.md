# Contributing

Thank you for helping improve APKWorld CLI.

Before opening a pull request:

1. Explain the user problem being solved.
2. Keep upstream acquisition, proxy rotation, credentials, and access-control
   bypass logic out of the project.
3. Add or update tests.
4. Run `npm run check` and `npm test`.
5. Keep application binaries and copied store content out of commits.

Apache License 2.0.
